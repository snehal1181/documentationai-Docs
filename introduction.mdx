## Overview

CodeCraftters provides a centralized space for teams to create, organize, and maintain project documentation. You can build structured docs with Markdown and MDX support, collaborate in real-time, and publish beautiful, searchable documentation sites. Customize themes with your brand colors, like `#D4AF37` for accents, to match your identity.

This platform streamlines workflows for developers and teams, reducing documentation silos and ensuring knowledge stays accessible.

## Quick Start

Get up and running in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create an account at `https://dashboard.example.com/signup`.
  </Step>
  <Step title="Create Workspace" icon="folder-plus">
    Set up a new project space and invite collaborators.
  </Step>
  <Step title="Add First Page" icon="plus">
    Write your initial doc using the editor.

    <CodeGroup tabs="Markdown,MDX">
    ````markdown
    # Welcome

    Your first documentation page.
    ````

    ````mdx
    ## Hello World

    Use components like `<Callout>` for rich content.
    ````
    </CodeGroup>
  </Step>
  <Step title="Publish" icon="globe">
    Deploy your site to `https://docs.example.com`.
  </Step>
</Steps>

## Customization Options

Tailor CodeCraftters to your brand:

- **Brand Colors**: Set primary color to `#D4AF37` in workspace settings.
- **Navigation**: Configure sidebar menus and search.
- **Components**: Enable MDX components for interactive docs.

<Expandable title="Advanced Theming" default-open="false">
  Edit `theme.config.js` to extend styles:

  ````javascript
  export default {
    color: {
      primary: '#D4AF37',
    },
  };
  ````
</Expandable>
