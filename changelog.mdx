## Upgrading to the Latest Version

Follow these steps to upgrade your CodeCraftters instance safely.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Create a full backup of your documentation spaces.

````bash
# Using the CLI tool
codecraftters backup --space=all --output=backup-$(date +%Y%m%d).tar.gz
````

  </Step>
  <Step title="Update Package" icon="download">

    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install codecraftters@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn add codecraftters@latest
````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Run Migrations" icon="settings">

    Apply database migrations for new features.

````bash
codecraftters migrate --version=2.1.0
````

    Review any breaking changes from v2.0.0 in the notes above.

  </Step>
  <Step title="Restart Service" icon="refresh-cw">

    Restart your CodeCraftters server.

````bash
codecraftters restart
````

  </Step>
</Steps>

<Callout kind="tip">
  After upgrading, test your key workflows like editing jewelry collection pages and image embeds.
</Callout>
